## なぜスプレッドシートの標準機能や通常の数式では限界があるのか？

大量のテキストデータを扱う際、多くのオフィスワーカーが直面するボトルネックは主に以下の3つです。

1. **条件分岐（IF関数など）の限界**
   「もし『不具合』という単語が含まれていれば…」という単純なIF関数では、ユーザーの複雑なニュアンス（例：「動かないわけではないが、使いにくい」など）を正確にキャッチできず、誤分類が続出します。
2. **手作業によるヒューマンエラーと時間の浪費**
   1000件のレビューを人間が目で見て判断すると、集中力が切れてミスが増える上、丸一日が潰れます。
3. **外部ツールを行き来する非効率さ**
   わざわざ別のAIチャット画面を開いて、1件ずつコピペして結果をスプレッドシートに貼り戻す作業は、タイムロスが大きすぎます。

## 実装ステップ：GASとGemini APIで爆速自動化を実現する

ここからは、実際にGoogleスプレッドシートとGemini APIを接続する手順を、3つのステップで分かりやすく解説します。

### ステップ1: Google Cloud (AI Studio) でAPIキーを取得する

まずは、Geminiの頭脳を借りるための「APIキー」を発行します。

1. ブラウザで **Google AI Studio** にアクセスし、Googleアカウントでログインします。
2. 画面左上にある **「Get API key」** ボタンをクリックします。
3. **「Create API key in new project」** を選択し、発行された英数字のキーをコピーしてメモ帳などに保存しておきます。
   * ※注意：APIキーはパスワードと同じです。他人に見られないよう厳重に管理してください。

### ステップ2: GoogleスプレッドシートにGASコードを書き込む

次に、スプレッドシート側からGemini APIを呼び出すためのプログラム（GAS）を準備します。

1. 集計用のGoogleスプレッドシートを開きます。
2. メニューバーの **「拡張機能」 > 「Apps Script」** をクリックします。
3. 開いたエディタ画面に、以下のコードを貼り付けます（既存のコードはすべて消去してください）。

```javascript
/**
 * スプレッドシートのカスタム関数としてGemini APIを呼び出し、テキストを分類する
 * @param {string} text 分類したいテキスト
 * @param {string} categories カンマ区切りのカテゴリー候補 (例: "ポジティブ,ネガティブ,要望,バグ")
 * @return {string} 判定されたカテゴリー
 * @customfunction
 */
function CLASSIFY_TEXT(text, categories) {
  if (!text) return "";

  // ステップ1で取得したご自身のAPIキーに書き換えてください
  const apiKey = "YOUR_GEMINI_API_KEY_HERE"; 
  const url = "https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=" + apiKey;

  const prompt = `以下のテキストを、次のカテゴリーの中から最も適切なものを1つだけ選んで答えてください。余計な説明は不要で、カテゴリー名のみを出力してください。\n\nカテゴリー候補: {categories}\n\nテキスト: "{text}"`;

  const payload = {
    "contents": [{
      "parts": [{
        "text": prompt
      }]
    }]
  };

  const options = {
    "method" : "post",
    "contentType" : "application/json",
    "payload" : JSON.stringify(payload),
    "muteHttpExceptions" : true
  };

  try {
    const response = UrlFetchApp.fetch(url, options);
    const json = JSON.parse(response.getContentText());
    
    if (json.candidates && json.candidates.length > 0) {
      return json.candidates[0].content.parts[0].text.trim();
    } else {
      return "Error: API Response Invalid";
    }
  } else {
    return "Error: Request Failed";
  }
}
```

4. コード内の `"YOUR_GEMINI_API_KEY_HERE"` の部分をご自身のAPIキーに書き換えます。
5. エディタ上部の **「保存」アイコン（フロッピーディスクのマーク）** をクリックします。

### ステップ3: スプレッドシート上で関数を実行する

設定が完了したら、いよいよスプレッドシート上でAIを動かします。

1. スプレッドシートに戻ります。例えば、A列に顧客からのレビューが入っているとします（A2セルに「アプリの起動が遅くてイライラする」、B2セルに候補カテゴリーとして `ポジティブ,ネガティブ,要望,バグ` と入力）。
2. 分類結果を表示したいC2セルに、以下のようにカスタム関数を入力します。
   ```text
   =CLASSIFY_TEXT(A2, "ポジティブ,ネガティブ,要望,バグ")
   ```
3. Enterを押すと、数秒後にGeminiが文脈を読み取り、「ネガティブ」といった結果が自動出力されます。
4. あとはC2セルの右下をダブルクリックして、1000行分の一番下までオートフィルするだけです。数秒で全データの仕分けが完了します。

## 専門家からの警告：実務で使う際の注意点とセキュリティ

生成AIを業務に組み込む際は、以下のポイントに十分注意してください。

* **機密情報の取り扱い（DLP / プライバシー）**
  顧客の個人情報や社外秘の機密データをそのままパブリックなAPIに送信することは、セキュリティポリシー違反になる可能性があります。社内規定を確認し、必要に応じて個人情報を黒塗り（マスキング）する前処理を挟むか、利用規約でデータ学習されないAPIプランを選択してください。
* **APIの利用制限とコスト管理**
  無料枠（Free Tier）には1分あたりのリクエスト数（RPM）制限があります。大量データを一気に処理する際は、ループ処理の間に `Utilities.sleep(1000);` （1秒待機）などのウェイトを入れるとエラーを防げます。
* **出力のゆらぎ対策**
  AIは時に指示以外の余計な言葉を出力することがあります。「カテゴリー名のみを出力してください」というプロンプトの強烈な指定や、GAS側で文字列をクリーニングする処理を入れておくと安心です。

## よくある質問（FAQ）

### Q1. プログラミング経験が全くありませんが、本当に使いこなせますか？
A. はい、ご安心ください！今回の記事で紹介したコードはコピペしてAPIキーを差し替えるだけで動くように設計しています。まずはテスト用のスプレッドシートで試してみてください。

### Q2. 「エラー」と表示されてしまいます。何が原因でしょうか？
A. 主に以下の3つが原因として考えられます。
1. APIキーの文字列が間違っている、または余計なスペースが入っている。
2. Google AI Studio側でAPIが有効化されていない。
3. コード内の関数名や構文にタイポ（入力ミス）がある。まずはログを確認してみましょう。

### Q3. 判定するカテゴリーを途中で増やしたり変更したりできますか？
A. はい、可能です。カスタム関数の第2引数（例: `"ポジティブ,ネガティブ,要望,バグ,その他"`）を書き換えるだけで、AIは新しいカテゴリーの基準を理解して柔軟に仕分け直してくれます。
