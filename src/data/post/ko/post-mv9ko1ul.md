시계 바늘은 이미 오후 6시 50분을 향해 달리고 있는데, 내 화면 속 구글 시트에는 고객 리뷰와 피드백 데이터 3,000건이 고스란히 남아있었다. 내일 아침 임원진 보고 전까지 이 방대한 텍스트를 '기능 오류', '가격 불만', 'UI 불편', '단순 칭찬' 네 가지 카테고리로 분류해서 요약해야 하는 상황. 

처음에는 VLOOKUP과 IF 함수 조합으로 어떻게든 비벼보려 했지만, 제멋대로인 비정형 텍스트 앞에서 엑셀 수식은 완전히 무력했다. 일일이 셀을 누르고 읽으면서 수작업으로 라벨링을 시작한 지 30분 만에 손목 통증과 함께 눈앞이 아득해졌다. '이러다 또 판교 밤거리를 보며 택시를 타겠구나' 하는 절망감이 밀려오는 순간, 문득 사무실 책상에 꽂아둔 구글 앱스 스크립트(Apps Script) 메모가 눈에 들어왔다.

### 수많은 실무자들이 대량 텍스트 분류에서 실패하는 이유 3가지

매번 보고서 시즌마다 텍스트 데이터 정제와 분류 작업에서 야근 사태가 벌어지는 이유는 명확하다. 우리가 마주하는 3가지 치명적인 병목 현상을 짚어보자.

1. **비정형 데이터의 한계 (정규식의 무능함)**
   고객들이 남긴 리뷰는 정형화되어 있지 않다. "배송이 너무 느려요"와 "택배 아저씨가 던지고 갔는데 박스가 찢어졌네요"는 표현은 다르지만 모두 '배송 불만'이다. 단순 엑셀 텍스트 함수나 IF 조건문으로는 이 미묘한 맥락을 절대 잡아낼 수 없다.
2. **반복적인 수작업으로 인한 휴먼 에러**
   복사해서 챗GPT나 제미나이 웹 대화창에 넣고 분류해달라고 요청한 뒤 다시 시트에 붙여넣는 작업을 반복하다 보면, 행이 밀리거나 누락되는 실수가 속출한다. 데이터가 500건을 넘어가면 이 방식은 정신 건강에 극도로 해롭다.
3. **API 연동에 대한 불필요한 막연함**
   "API", "스크립트", "JSON" 같은 단어가 나오면 개발자 영역이라고 선을 긋는다. 하지만 구글 시트의 [확장 프로그램 > Apps Script] 환경은 10줄 내외의 자바스크립트 코드만으로도 누구나 강력한 AI 봇을 내 시트 안에 심을 수 있는 엄청난 무기다.

### Step-by-Step 실전 해결 가이드: 구글 시트 + 제미나이 API 연결하기

이제 본격적으로 야근을 막아줄 자동화 파이프라인을 구축해 보자. 개발 지식이 전혀 없어도 아래 순서대로 클릭하고 코드를 붙여넣으면 5분 만에 끝난다.

#### 1단계: 구글 AI Studio에서 제미나이 API 키 발급받기
1. 웹브라우저에서 Google AI Studio (aistudio.google.com)에 접속한다.
2. 구글 계정으로 로그인한 뒤, 화면 좌측 상단의 **'Get API key'** 버튼을 클릭한다.
3. **'Create API key'**를 눌러 새 키를 생성하고, 발급된 영문+숫자 조합의 키를 메모장에 안전하게 복사해 둔다. (이 키는 타인에게 절대 노출되면 안 된다.)

#### 2단계: 구글 시트 준비 및 커스텀 함수 세팅
1. 분류할 텍스트가 담긴 구글 시트를 연다. (예: A열에 고객 피드백 내용, B열에 분류 결과가 들어갈 예정)
2. 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭하여 스크립트 편집기 창을 연다.
3. 기존에 있던 코드를 모두 지우고, 아래의 실전 코드를 그대로 복사해서 붙여넣는다.

```javascript
/**
 * 구글 시트에서 직접 호출하는 제미나이 텍스트 분류 커스텀 함수
 * 사용법: =GEMINI_CLASSIFY(A2)
 */
function GEMINI_CLASSIFY(text) {
  if (!text) return "";

  // 본인의 구글 AI Studio API 키를 아래에 입력하세요
  var apiKey = "여기에_발급받은_API키를_입력하세요";
  var url = "https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=" + apiKey;

  var prompt = "다음 텍스트를 정확히 다음 4가지 카테고리(기능오류, 가격불만, UI불펜, 단순칭찬) 중 하나로만 분류해 단답으로 출력해줘. 다른 설명은 절대 붙이지 마.\n\n텍스트: " + text;

  var payload = {
    "contents": [{
      "parts": [{
        "text": prompt
      }]
    }]
  };

  var options = {
    "method" : "post",
    "contentType": "application/json",
    "payload" : JSON.stringify(payload),
    "muteHttpExceptions": true
  };

  try {
    var response = UrlFetchApp.fetch(url, options);
    var data = JSON.parse(response.getContentText());
    
    if (data.candidates && data.candidates[0].content) {
      return data.candidates[0].content.parts[0].text.trim();
    } else {
      return "분류 오류";
    }
  } catch (error) {
    return "통신 에러: " + error.message;
  }
}
```

4. 코드 내의 `"여기에_발급받은_API키를_입력하세요"` 부분을 아까 복사해 둔 본인의 API 키로 교체한다.
5. 상단의 **[저장(디스크 아이콘)]** 버튼을 누른다.

#### 3단계: 시트에서 함수 실행 및 대량 자동 분류 완료
1. 구글 시트로 돌아온다.
2. 분류 결과를 띄울 셀(예: B2)에 다음과 같이 입력한다.
   `=GEMINI_CLASSIFY(A2)`
3. 엔터를 치면 잠시 후 제미나이 API가 실시간으로 텍스트를 읽고 'UI불편' 또는 '기능오류' 같은 카테고리를 뱉어낸다.
4. B2 셀의 우측 하단을 잡고 아래로 쭉 드래그(자동 채우기)하면, 수천 건의 피드백이 순식간에 AI에 의해 완벽하게 분류된다.

<div style="border-left: 4px solid #ef4444; padding: 12px 16px; margin: 20px 0; background-color: rgba(0,0,0,0.03); border-radius: 4px; color: #111827;">
<strong>실무 꿀팁:</strong> 데이터가 1,000건 이상으로 너무 많을 때는 한 번에 함수를 걸면 API 호출 제한(Rate Limit)에 걸릴 수 있습니다. 이럴 때는 200~300건씩 끊어서 복사하거나, 스크립트 내에 <code>Utilities.sleep(500);</code> 같은 대기 시간을 추가해 주면 에러 없이 안정적으로 대량 처리가 가능합니다.

### 실무 전문가의 보안 및 운영 경고 (이것만은 꼭 지키세요!)

* **개인정보 및 기밀 데이터 주의:** 사내 인사이트 보고서나 고객의 민감한 개인정보(연락처, 주민번호 등)가 포함된 원본 텍스트를 외부 API로 전송할 때는 반드시 마스킹(비식별화) 처리를 거치거나 회사의 보안 가이드라인을 준수해야 합니다.
* **API 키 하드코딩 지양:** 위 예시에서는 편의상 코드에 직접 키를 넣었지만, 실제 운영 환경에서는 `PropertiesService`를 활용해 스크립트 속성에 키를 안전하게 숨겨두는 것이 보안상 안전합니다.

### 자주 묻는 질문 (FAQ)

**Q1. 수백 건을 동시에 드래그해서 채웠더니 '오류'나 '제한 초과' 메시지가 뜹니다. 어떻게 해야 하나요?**
A. 제미나이 무료 API(Gemini 1.5 Flash 등)는 분당 요청 수(RPM) 제한이 있습니다. 수천 건을 한 번에 불러오려다 보면 일시적인 트래픽 제한에 걸릴 수 있습니다. 이럴 때는 시트를 200행 단위로 나누어 순차적으로 수식을 적용하거나, 스크립트 코드 실행 시 반복문 사이에 0.5초 정도의 지연 시간을 주는 방식으로 해결할 수 있습니다.

**Q2. 분류된 카테고리를 내가 원하는 단어들로 커스텀할 수 있나요?**
A. 물론입니다. Apps Script 코드 내부의 `prompt` 변수 문자열 부분에서 `"기능오류, 가격불만, UI불펜, 단순칭찬"`으로 지정된 카테고리 목록을 담당 업무에 맞게 수정하시면 됩니다. 예를 들어 "버그, 결제, UI, 칭찬, 기타" 등으로 자유롭게 바꿀 수 있습니다.

**Q3. 엑셀(Microsoft Excel) 파일에서도 이 방식을 그대로 쓸 수 있나요?**
A. 안타깝게도 MS 엑셀의 VBA 환경은 구글의 Apps Script처럼 직관적인 웹 기반 외부 API fetch 처리가 상대적으로 까다롭고 보안 설정이 복잡합니다. 대량 텍스트 AI 자동화가 시급한 상황이라면, 엑셀 파일을 구글 드라이브에 업로드하여 구글 시트 형식으로 변환한 뒤 위 가이드를 적용하는 것이 가장 빠르고 확실한 야근 탈출 지름길입니다.
