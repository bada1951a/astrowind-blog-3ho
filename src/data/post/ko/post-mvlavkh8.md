### 왜 주소와 전화번호 분리 작업은 늘 이렇게 꼬일까요?

실무에서 고객 정보를 다루다 보면 데이터가 엉키는 원인은 대개 정해져 있습니다. 이번 사본 대란 사태를 겪으며 분석해 본 대표적인 업무 병목 원인 3가지는 다음과 같습니다.

첫째, 입력 형식이 제각각인 비정형 데이터의 한계입니다. 고객들이 웹폼에 주소를 입력할 때 도로명 주소만 적거나 상세 주소를 누락하고, 전화번호 역시 010-0000-0000 형태부터 01000000000, 또는 하이픈 없이 붙여 쓰는 등 규칙이 없어 단순 엑셀 함수로는 일괄 처리가 불가능합니다.

둘째, 클라우드 드라이브의 동시 편집 충돌로 인한 데이터 병합 오류입니다. 여러 명이 동시에 시트를 수정하다 보니 텍스트 서식이 일반 텍스트로 깨지거나 셸 서식 자체가 망가져 기존에 걸어두었던 텍스트 나누기 서식마저 무력화되었습니다.

셋째, 수작업 수정에 따른 인적 오류(Human Error) 위험입니다. 급한 마음에 마우스와 키보드로 직접 셀을 복사해 붙여넣기를 반복하다 보면 행이 밀리거나 전화번호가 주소란에 입력되는 등 치명적인 실수가 발생하여 오히려 검수 시간이 더 오래 걸리게 됩니다.

### 챗GPT와 엑셀을 결합한 3단계 초고속 해결 솔루션

이 복잡한 문제를 해결하기 위해 데이터 탭의 파워 쿼리 기능과 챗GPT가 생성해 주는 맞춤형 수식을 조합하는 가장 효율적인 프로세스를 공개합니다.

#### 1단계: 챗GPT에게 정확한 데이터 샘플과 요구사항 전달하기
먼저 엉망이 된 데이터 중 대표적인 샘플 3 - 4개를 복사합니다. 그리고 챗GPT 대화창에 아래와 같은 프롬프트를 입력하여 주소와 전화번호를 완벽하게 분리해 주는 엑셀 함수나 파워 쿼리 코드를 요청합니다.

```text
엑셀 한 셀에 주소와 전화번호가 섞여 있어. 아래 샘플 데이터를 보고 주소와 전화번호를 각각 별도의 열로 깔끔하게 분리할 수 있는 엑셀 수식(또는 텍스트 나누기 가이드)을 작성해줘. 전화번호는 항상 010으로 시작하고 하이픈이 있거나 없을 수 있어.

[샘플 데이터]
서울시 강남구 테헤란로 123 5층 010-1234-5678
경기도 성남시 분당구 판교역로 456 에이동 01098765432
부산광역시 해운대구 센텀중앙로 789 010-5555-4444
```

#### 2단계: 챗GPT가 제안한 수식 적용 및 검증하기
챗GPT가 반환해 준 정규식 기반 수식이나 함수를 엑셀 파일에 적용합니다. 최신 엑셀 버전을 사용 중이라면 텍스트 분할 함수나 파워 쿼리의 '구분 기호로 열 분할' 기능을 챗GPT의 가이드에 따라 실행합니다.

파일 > 옵션 메뉴나 데이터 탭의 파워 쿼리 편집기를 활용하면 복잡한 수식 없이도 텍스트 패턴을 인식해 단 몇 번의 클릭으로 열을 나눌 수 있습니다. 챗GPT가 알려준 사용자 정의 함수 코드가 있다면 데이터 탭의 고급 편집기에 붙여넣어 일괄 처리를 진행합니다.

#### 3단계: 최종 데이터 정합성 검수 및 시트 정리하기
분리가 완료된 데이터 열에서 전화번호 형식이 올바른지, 주소에 잘린 부분이 없는지 필터 기능을 이용해 샘플링 검사를 진행합니다. 이상이 없다면 기존의 뒤엉킨 원본 열은 숨기거나 삭제하고, 사본 충돌 마크가 없는 최종 깨끗한 시트를 완성합니다.

### 자주 묻는 질문 (FAQ)

Q1. 주소와 전화번호 사이에 일정한 구분 기호(쉼표나 탭)가 없는데도 챗GPT가 분리할 수 있나요?

A1. 네, 가능합니다. 전화번호는 항상 '010'으로 시작하고 11자리 숫자라는 패턴이 존재하기 때문에, 챗GPT는 이 패턴을 인식하여 숫자가 시작되는 지점을 기준으로 텍스트를 나누는 수식을 정확하게 만들어 줍니다.

Q2. 파워 쿼리를 쓰면 엑셀 파일 용량이 커지거나 에러가 나지 않나요?

A2. 파워 쿼리는 대용량 데이터를 다룰 때 오히려 엑셀을 가볍게 유지해 주는 강력한 도구입니다. 다만 원본 데이터 소스 경로가 사본 충돌로 인해 변경되면 오류가 날 수 있으므로, 분리 작업이 끝난 후에는 값(Value)으로 복사하여 붙여넣기 한 뒤 쿼리를 해제하는 것이 안전합니다.

Q3. 챗GPT가 만들어준 수식이 한글 버전 엑셀에서 #VALUE! 에러를 뿜어냅니다. 어떻게 해야 하나요?

A3. 영문 함수명(TEXTBEFORE, TEXTAFTER 등)이 한글 엑셀 버전에서 인식되지 않거나 인수가 맞지 않아 발생하는 현상입니다. 이럴 때는 챗GPT에게 "한글 엑셀 환경에서 쓸 수 있는 함수로 수정해줘"라고 추가 질문을 하거나, 구버전 엑셀도 지원하는 LEFT, RIGHT, FIND 함수 조합으로 다시 짜달라고 요청하면 즉시 해결됩니다.
